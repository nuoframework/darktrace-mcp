## Baseline decisions

| ID | Final baseline decision | Gate and evidence boundary |
|---|---|---|
| A1 | One HTTPS origin, credential pair and process; stdio only. No HTTP config/handler/listener, transport.kind accepts only stdio. | HTTP needs a separate threat model/auth design and ST-16 extensions. |
| A2 | Code-owned inventory keyed by operationId controls permission at registration, dispatch and execution. Unknown/blocked operations never reach signer. POST Advanced Search requires operator sensitiveRead, false by default; email POST denied. | Reviewed inventory changes and exact 79-operation coverage; a method/annotation/version never grants permission. |
| A3 | Startup auth.querySignatureEncoding is encoded or unencoded; default unencoded follows local SDK evidence and remains lab-unverified. Serialize once, preserve order, never fallback on 401. S4 query+JSON, S5 DELETE+query and S6 base64GET blocked. | Authorized lab evidence is pending; a result alone cannot toggle production shape gates. |
| A4 | Export config rejected and runtime denied. Future writer: operator-owned 0700 directory handle, generated names, exclusive no-follow relative 0600 files, 200,000,000 bytes/file, 1 GiB aggregate, 100 files, 1 concurrent job, atomic reservations and partial cleanup. Completed retention/deletion is operator-owned; no automatic deletion/upload. | Separate activation review and full ST-09/10/11; descriptor-owned binary budget cannot be selected by caller. |
| A5 | Critical permanently non-executable in baseline. writeCritical=true without write is a startup error. Five non-email operations may register preview-only with write+writeCritical; email action wholly blocked. No confirm field, signer or network execution branch. | Future trusted host approval must be a separate reviewed design, bound to exact request, single-use and expiring; no baseline flag enables it. |
| A6 | Every accepted dry-run returns exactly {dryRun:true, operationId, method, parameterNames} before build/sign; no values or extra fields. Medium/high default dryRun:true. Dedicated pinned node:https with rejectUnauthorized:true; private CA via NODE_EXTRA_CA_CERTS; reject TLS/proxy bypass environment/flags. | Invariants. Trusted operator NODE_OPTIONS can execute arbitrary preloads; hostile operator/OS is outside process isolation. |
| A7 | Email profile rejected at load; all 14 email operations denied regardless of code presence. No runtime/per-deployment schema generation. | Authorized retrieval, pinned reviewed committed instance schema, S9 resolution and new design review are prerequisites for future proposals. |
| A8 | 30,000 ms **total** incl queue/retries/pages, attempt at most remaining time; input 64 KiB / depth 8 / elements 5,000; response 2 MiB wire AND decoded with identity encoding; output 60,000 chars; concurrent 4 / queue 16 / pages 10; rate 120 attempts/minute; max 2 safe-GET retries; invalid/excessive Retry-After means no retry, missing-header own backoff at most 2 s within deadline; no POST/DELETE retry. | Settings may only lower ceilings. Capacity and live compatibility remain external validation pending. |

The coordinator's final decisions deliberately tighten the review proposal: A8 uses **30 s total**, not its proposed 60 s, and a **2 s maximum acceptable Retry-After**, not its proposed 30 s; excessive/invalid server waits cause no retry, never truncation to an earlier attempt; byte limits use **MiB** exactly. F6 is resolved with default-off sensitiveRead rather than the review's default-on proposal. B3 uses dedicated `node:https` rather than the review's suggested undici Agent; actual pinned connection, SNI and hostname checks remain mandatory. The finalized allowlist accepts only canonical IPv4/IPv6 exact addresses and rejects CIDR; initialization is lazy before the first eligible signer/socket, with no automatic status probe. A failed lazy DNS initialization is terminal until process restart, superseding the round-3 suggestion of retrying on a later call. These decisions supersede proposals, without changing any of the four historical reviews.
